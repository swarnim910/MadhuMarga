# 🐝 Madhu-Marga (Agriculture)

**Madhu-Marga** ("Path of Honey") is a native Android application built as a **Digital Beekeeper's Diary**. It acts as an AI-guided assistant for hive management, helping farmers and beekeepers track their apiaries, monitor hive health, log honey harvests, and maximize yield based on seasonal flora.

---

## 🌟 Features

*   **Hive Register:** Easily add and manage bee colonies with unique tags and locations.
*   **Inspection Log:** Record observations using a smart checklist (e.g., "Queen seen", "Pests seen").
*   **Harvest Tracker:** Log the quantity of honey collected from each hive and view a Year-over-Year (YoY) comparison of your production.
*   **Flora Calendar:** A visual guide indicating which Indian flora are blooming each month to help maximize nectar flow.
*   **Decision Matrix (Intervention Alerts):** Intelligent logic that analyzes your inspection logs (like "Low Activity") and generates proactive alerts suggesting when to intervene, split a colony, or prepare for harvest.

## 🛠️ Tech Stack

This project was built entirely using modern Android development practices:

*   **Language:** [Kotlin](https://kotlinlang.org/)

*   **Architecture:** MVVM (Model-View-ViewModel) + Repository Pattern
*   **Local Database:** [Room Database](https://developer.android.com/training/data-storage/room)
*   **Asynchronous Programming:** Kotlin Coroutines & Flow
*   **Navigation:** Navigation Compose
*   **Build System:** Gradle Kotlin DSL (`.kts`)

## 🚀 Getting Started

### Prerequisites

*   [Android Studio](https://developer.android.com/studio) (Giraffe or newer recommended)
*   Android SDK (API Level 26 or higher)

### Installation

1.  **Clone the repository** (if applicable) or open the project folder in Android Studio.
    ```bash
    git clone https://github.com/yourusername/madhu-marga.git
    ```
2.  **Open the Project:**
    Open Android Studio -> `File` -> `Open` -> Select the `Madhu Marga` directory.
3.  **Sync Gradle:**
    Android Studio should automatically sync the Gradle files. If not, click the "Sync Project with Gradle Files" icon.
4.  **Run the App:**
    Select an emulator or a connected physical device and click the ▶️ **Run** button.
